# Финальный проект по PostgreSQL

* **Студент:** Курмашев Артур
* **Тема:** База данных магазина цифровых игр (информация о разработчиках, играх, пользователях, покупках и отзывах).
* **Название БД:** `gamestore_db`
* **Название схемы:** `store`

## Инструкция по запуску:
1. Создайте пустую базу данных `gamestore_db`.
2. Запустите на ней скрипт `02_final.sql`.
